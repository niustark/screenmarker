# 画屏点睛

一款轻量、免安装的 Windows 桌面标注工具。双击即用，随时在屏幕上画圈、划线、打马赛克、加文字水印，适合录屏讲解、远程协作、演示汇报、截图说明等场景。

---

## 特色

- **免安装**：单文件 exe，双击即用，无需安装、不写注册表、不留后台服务。
- **轻量低占用**：原生 Rust + Win32 实现，单文件约 420 KB，常驻内存占用极低。
- **悬浮工具条**：平时收纳成一个半透明小图标，需要时一键展开，不挡视线。
- **画完即穿透**：标注图层悬浮在所有窗口之上，画完可让鼠标穿透过去，不干扰下层程序。
- **画完即选中**：图形一落定就带选中框，可立刻拖动、拉手柄缩放、滚轮缩放、按 `Del` 删除。
- **图形可再编辑**：画好的线条、形状随时能重新选中、移动、缩放、删除，右键点击图形即可删掉它。
- **只跑一个实例**：无论 exe 放在哪个目录、点多少次，屏幕上始终只有一个工具条。

## 快速开始

1. 双击运行 exe。
2. 屏幕上出现一个**半透明的铅笔图标**（收纳态）。
3. 点击该图标（或按右侧 `Ctrl`）展开工具条，默认已选中「荧光笔」，直接在屏幕上拖动即可划重点。
4. 想换工具就点对应按钮（如「画笔」「矩形」），再在屏幕上拖动画出。
5. 画完点击铅笔图标收纳工具条，标注仍留在屏幕上，鼠标可以直接操作下层程序；按 `Esc` 则是整体退出标注（画布收起，图形仍在内存里，下次选工具会回来）。

> 托盘区（任务栏右下角）会常驻一个图标，右键可打开「关于」或「退出」。

### 颜色与粗细

- **7 种颜色**：红、橙、黄、绿、蓝、白、黑，点色块切换。
- **线宽 / 字号滑块**：拖动滑块调整线条粗细，同时决定文字字号。
- **鼠标滚轮**：有选中图形时缩放该图形（每格约 10%）；没有选中时才调节当前工具的线宽 / 大小。

### 常用操作

- **撤回**：撤销上一步。
- **擦除**：擦掉画过的图形。
- **清空**：一键清除全部标注（也可以双击右侧 `Ctrl`）。
- **选择**：点选已画图形后可拖动移动、拉四角/四边手柄缩放、滚轮缩放，按 `Del` / `Backspace` 或右键该图形删除。

## 使用技巧

### 悬浮标注，画完穿透

标注图层置顶悬浮，画完后进入「穿透态」——标注内容仍然显示在屏幕上，但鼠标点击会直接穿透到下层的程序，不影响你继续操作电脑。需要重新编辑时，点击铅笔图标激活即可。

### 图形可二次编辑

画好的图形不是「一次性」的：**图形一落定就自动带选中框**，可以直接拖动移动、拉四角 / 四边的小方块缩放、滚滚轮缩放，按 `Del` 删除，右键点图形也能直接删掉它。当前工具不会被切换，删完可以接着在旁边画下一个。

### 水印就是一层开关

点「水印」按钮 → 弹出文字框（默认「画屏点睛」）→ 回车，全屏就铺上斜 28° 的平铺水印。开着水印时标注层对鼠标是透明的：你能直接在下层浏览器里选字、点输入框，水印只是叠在画面上。

**关掉只要一步**：再点一次水印按钮，或按 `Esc`，水印立刻消失，其它标注都留着。想改文字就关掉再点开，输入框会自动带上上次的内容；字号用 `Ctrl` + 滚轮调。

### 半透明收纳态

工具条不使用时收纳成一个半透明铅笔图标，几乎不干扰视线，随时一键唤出。鼠标移到图标上会浮出提示气泡：**「点击或按右侧 Ctrl 键展开工具条」**。

### 全局只运行一个实例

启动时程序会占用一个系统级的唯一名额，这个名字与 exe 的路径、文件名都无关。所以无论把 exe 复制到多少个目录、改成什么名字，从快捷方式还是资源管理器双击，同一时间只会有一个进程在跑。后来的启动请求会唤醒已运行实例的工具条（收纳态会自动展开），然后安静退出——不会叠出第二个悬浮图标。

### 快捷键的选择

展开 / 收纳使用**右侧 `Ctrl`**：它单独按下时几乎没有任何用途，不影响打字与输入法，也不会与常见的组合键冲突。按住 `Shift` / `Alt` / 左侧 `Ctrl` / `Win` 再按右侧 `Ctrl` 不会触发，可放心使用各类组合键。

## 使用注意事项

1. **系统要求**：Windows 7 及以上（64 位），建议 Windows 10 / 11。
2. **杀毒软件提示**：本软件使用键盘 / 鼠标底层钩子实现全局快捷键，部分安全软件可能误报为「键盘记录」。此为正常行为，请选择「允许」或「添加信任」。软件**不会**记录或上传任何键盘输入。
3. **鼠标穿透说明**：画完图进入穿透态后，空白处的点击会穿透到下层程序；**已经画好的图形仍能点选、拖动，右键点击即可删除**。要画新东西或点工具条，先点铅笔图标重新激活。
4. **关于录屏**：标注图层置顶悬浮，录屏时会一并被录制；若只想保留标注不想让工具条入镜，先收纳工具条再开始录。
5. **数据不保存**：标注内容仅在内存中，关闭程序即清空，不会写入任何文件。
6. **多显示器**：标注画布覆盖主屏区域，多屏环境请在主屏使用。

## 常见问题（FAQ）

**Q：为什么点了工具但画不出来？**
A：点击工具后画布会自动显示；若仍无反应，请确认没有其他全屏应用（如游戏）抢占焦点。

**Q：标注挡住了下面的内容，怎么点不到？**
A：当前处于「穿透态」，鼠标会穿透标注层。点击铅笔图标重新激活工具条后即可正常点选标注。

**Q：怎么退出程序？**
A：在收纳状态下用右键点主图标即可退出；也可以托盘区右键程序图标 → 选择「退出」。

> 注意：主图标（收纳态）右键会**直接退出**，不会弹菜单。

**Q：双击 exe 后没弹出新窗口，是不是没启动？**
A：不是。程序全局只允许一个实例，第二次双击只是把已运行的工具条唤出来（收纳态会自动展开），不会再启动第二个进程。

**Q：Windows 提示「无法运行」或被杀软拦截？**
A：这是单文件便携程序，被误报属常见情况。将 exe 添加到安全软件信任名单即可。
