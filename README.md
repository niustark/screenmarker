# 屏幕标注 ScreenMarker

一款轻量、免安装的 Windows 屏幕标注工具。开机即用，随时在屏幕上画圈、划线、打马赛克、加文字水印，适合录屏讲解、远程协作、演示汇报、截图说明等场景。

- **免安装**：单文件 exe，双击即用，无需安装、不写注册表、不留后台服务。
- **轻量低占用**：纯原生 Win32 实现，无 Electron、无运行时依赖，内存占用极小。
- **悬浮工具条**：平时收纳成一个半透明小图标，需要时一键展开，不挡视线。
- **真·屏幕标注**：标注图层悬浮在所有窗口之上，画完可鼠标穿透，不干扰下层操作。

## 快速开始

1. 双击运行 `screenmarker.exe`。
2. 屏幕底部会出现一个**半透明的铅笔图标**（收纳态）。
3. 点击该图标，展开完整工具条，即可开始标注。
4. 选一个工具（如「画笔」「矩形」），直接在屏幕上拖动画出。
5. 完成后点击铅笔图标（或按 `Esc`）收纳工具条，标注内容保留在屏幕上。

> 托盘区（任务栏右下角）会常驻一个图标，右键可打开「关于」或「退出」。

| --- | --- |

| 矩形 | 画矩形框 |
| 圆 | 画椭圆/圆形 |
| 文字 | 点击屏幕任意处输入文字 |
| 箭头 | 画带箭头的指向线 |
| 折线 | 连续点击绘制多段折线 |
| 波浪 | 画波浪下划线，适合圈注 |
| 放大镜 | 局部放大区域（滚轮调范围，Ctrl+滚轮调倍率） |
| 聚光 | 高亮聚光灯效果，突出局部 |
| 水印 | 全屏平铺文字水印 |
| 序号 | 依次标注 ①②③… 序号 |
| 马赛克 | 矩形区域打码（滚轮调区域大小） |

### 颜色与粗细

- **7 种颜色**：红、橙、黄、绿、蓝、白、黑，点色块切换。
- **线宽/字号滑块**：拖动滑块调整线条粗细（同时决定文字字号）。
- 也可以用**鼠标滚轮**快速调节当前工具的线宽/大小。

### 常用操作

- **撤回**：撤销上一步。
- **擦除**：擦掉画过的图形。
- **清空**：一键清除全部标注。
- **选择**：点选已画图形后，可拖动移动、滚轮缩放，按 `Del` 或 `Backspace` 删除。

## 核心特性详解

### 悬浮标注，画完穿透

标注图层置顶悬浮，画完后进入「穿透态」——标注内容仍然显示在屏幕上，但鼠标点击会直接穿透到下层的程序，不影响你继续操作电脑。需要重新编辑时，点击铅笔图标激活即可。

### 图形可二次编辑

画好的图形不是「一次性」的：切到「选择」工具（或画完点右键进入选择态），即可点选任意图形，进行移动、滚轮缩放、删除等操作。

### 半透明收纳态

工具条不使用时收纳成一个半透明铅笔图标，几乎不干扰视线，随时一键唤出。鼠标移到图标上会浮出提示气泡：**「点击或按右侧 Ctrl 键展开工具条」**。

### 为什么用右侧 Ctrl 而不是空格

空格是最常被输入的字符，用它做全局快捷键极易在打字、输入法选词时误触。右侧 `Ctrl` 单独按下时几乎没有任何用途，且不会与输入法的组合键冲突，因此被选作展开 / 收纳的快捷键。按住 `Shift` / `Alt` / 左侧 `Ctrl` / `Win` 再按右侧 `Ctrl` 不会触发，可放心使用各类组合键。

## 使用注意事项

1. **系统要求**：Windows 7 及以上（64 位）。建议 Windows 10 / 11。
2. **杀毒软件提示**：本软件使用键盘/鼠标底层钩子实现全局快捷键，部分安全软件可能误报为「键盘记录」。此为正常行为，请选择「允许」或「添加信任」。软件**不会**记录或上传任何键盘输入。
3. **鼠标穿透说明**：画完图进入穿透态后，标注区域无法用鼠标点击选中（鼠标会穿透到下层程序）。如需编辑标注，请先点击铅笔图标重新激活工具条。
4. **关于录屏**：标注图层置顶悬浮，录屏时会一并被录制；若只想保留标注不想让工具条入镜，先收纳工具条再开始录。
5. **数据不保存**：标注内容仅在内存中，关闭程序即清空，不会写入任何文件。
6. **多显示器**：标注画布覆盖主屏区域，多屏环境请在主屏使用。

## 常见问题（FAQ）

**Q：为什么点了工具但画不出来？**
A：点击工具后画布会自动显示；若仍无反应，请确认没有其他全屏应用（如游戏）抢占焦点。

**Q：标注挡住了下面的内容，怎么点不到？**
A：当前处于「穿透态」，鼠标会穿透标注层。点击铅笔图标重新激活工具条后即可正常点选标注。

**Q：怎么退出程序？**
A：托盘区右键程序图标 → 选择「退出」。

**Q：Windows 提示「无法运行」或被杀软拦截？**
A：这是单文件便携程序，被误报属常见情况。将 exe 添加到安全软件信任名单即可。
